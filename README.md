# SALES-OS

AI와 대화하면서 프로젝트, 업무 자료, 연결한 서비스를 함께 관리하는 업무 비서입니다.

## 주요 기능

- **프로젝트와 대화**: 프로젝트별로 대화를 모으고, AI가 작성한 Markdown 요약으로 진행 상황을 확인합니다. `요약 수정`에서 원하는 수정 방향을 요청할 수 있습니다.
- **서비스 연결**: Google Drive·Gmail·Sheets·Chat·Calendar와 Notion을 연결합니다. Google은 여러 계정을 추가하고 계정별 자료 사용을 켜거나 끌 수 있습니다.
- **자료 분석**: 채팅에 이미지나 문서를 첨부해 내용을 정리하고, `자료`에서 업로드한 파일 목록을 확인합니다.
- **로컬 폴더**: Windows 연결 프로그램으로 허용한 폴더의 파일을 검색하고 읽습니다.
- **LINE과 자동화**: LINE 및 n8n을 설정해 모바일 대화와 업무 알림·후속 처리 워크플로우를 연결합니다.

프로젝트와 연결 계정은 사용자별로 관리합니다. 서비스 연결에는 해당 계정의 동의가 필요하며, 외부 서비스 기능은 관리자의 연동 설정 후 사용할 수 있습니다.

## 사용 방법

1. 관리자에게 이용할 이메일을 등록받고 로그인합니다.
2. `서비스 연결`에서 사용할 계정을 추가합니다. Google은 이미 연결한 서비스도 눌러 다른 계정을 추가할 수 있습니다.
3. 새 대화를 시작하거나 `워크스페이스`에서 프로젝트를 만듭니다.
4. 업무를 요청하고 필요한 자료를 첨부합니다. 프로젝트 개요와 `내 작업`에서 결과를 확인합니다.
5. PC 자료가 필요하면 `로컬`에서 연결 코드를 발급받아 별도 연결 프로그램에 등록합니다.

## 구성

| 기술 | 사용하는 기능 |
| --- | --- |
| React Router · Tailwind | 웹 화면, 로그인과 화면별 요청 처리 |
| OpenAI ChatKit · OpenAI API | AI 채팅, 자료 분석, 프로젝트 요약 |
| Supabase | 로그인, 데이터베이스, 파일 저장 |
| Python | AI 도구 실행과 외부 서비스 연결 |
| n8n · LINE | 메신저 연결과 업무 자동화 |
| Electron | Windows의 지정 폴더 읽기 |

## 직접 실행하기

Node.js 22.22 이상, Python 3.12 이상, `uv`가 필요합니다.

`.env.example`을 `.runtime/server.env`로 복사한 뒤 본인의 설정을 입력합니다. 관리자는 Supabase 마이그레이션·로그인, OpenAI API·ChatKit 도메인을 설정하고 `SALESOS_ADMIN_EMAILS`에 관리자 이메일을 지정해야 합니다. Google·Notion·LINE·n8n과 PC 연결은 사용할 기능에 맞춰 별도로 설정합니다.

```sh
npm ci
uv sync --directory services/api --frozen
npm run dev
```

웹은 `http://127.0.0.1:5173`에서 실행됩니다. 실제 키와 환경파일은 저장소에 올리지 않습니다. OpenAI API와 연결 서비스의 이용 요금은 각 서비스 계정에 적용됩니다.

Docker로 배포할 때는 `SALESOS_PUBLIC_URL`에 서비스 주소를 지정하고 `docker compose up --build`를 실행합니다.
